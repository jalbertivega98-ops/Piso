# Piso 3D

Modelo 3D de mi vivienda para ver en el navegador, con muebles que se pueden mover y quitar.

## Qué subir a la carpeta `uploads/`

1. **Plano con medidas**: foto o PDF del plano, o un dibujo a mano con el largo y ancho de cada habitación (en cm).
2. **Altura del techo**: una medida por habitación si cambia (por ejemplo, 250 cm).
3. **Puertas y ventanas**: en qué pared están, su ancho y alto, y la altura de la ventana desde el suelo.
4. **Fotos**: una o dos por habitación, desde las esquinas, para ver suelos, paredes y muebles.
5. **Muebles (opcional)**: lista de los muebles principales con sus medidas aproximadas.

## Cómo subir archivos

En GitHub, entra en la carpeta `uploads`, pulsa **Add file → Upload files**, arrastra los archivos y pulsa **Commit changes**.
